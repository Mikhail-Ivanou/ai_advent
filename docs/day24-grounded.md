## Выводы

Режимы: **baseline** — поиск top-5 без порога; **ce** — 20 кандидатов → cross-encoder → порог 0.2 (режим чата по умолчанию); **llm** — 20 → LLM-реранкер → порог 0.6. Во всех трёх ответ обязан быть в формате «ответ + источники + цитаты» и проходит проверку на сервере.

- **Источники есть в каждом ответе.** Во всех режимах: 7/7 выданных ответов. Источники строятся из метаданных реально найденных чанков (файл › раздел, `chunk_id`), а не из текста модели.
- **Цитаты есть в каждом ответе.** Тоже 7/7. Подтверждено 32 цитаты из 32, 31 из них дословно, одна склеена из двух дословных кусков через «[…]».
- **Смысл ответа совпадает с цитатами.** Проверяющая LLM видит только ответ и цитаты. Итог: 12 «да», 9 «частично», 0 «нет». «Частично» означает, что ответ шире цитат: модель берёт детали из того же фрагмента, но цитирует не всё. Пример: в q4 описание превращения Белова есть во фрагменте, но не в выбранных цитатах. Ни один ответ не противоречит своим цитатам.
- **«Не знаю» при слабом контексте.** Все 3 вопроса не по книге в режимах ce и llm получают «не знаю» без вызова LLM: лучшая релевантность от 0.003 до 0.12 при пороге 0.2 (у LLM-реранкера 0 при пороге 0.6), плюс просьба уточнить и ближайшие разделы. В baseline порога нет, фрагменты уходят в LLM, и модель сама отвечает «НЕ ЗНАЮ».
- **«Не знаю» на вопросах с ответом** — q3, q5, q8 во всех режимах. Фрагмента с ответом не было в контексте, и модель честно отказалась, вместо того чтобы сочинять. Это промах поиска, а не генерации, см. выводы дня 23.
- **Выдумок 0.** Судья отметил две (q4 в режиме llm, q5 в baseline), но обе ссылаются на нашивку «Белов К. С. Россия», а она в книге есть: судья сверяется только с коротким эталоном. Без RAG модель выдумала в 11 ответах из 13. В дне 23, до обязательных цитат, было до 4 выдумок на режим.
- **Ошибки судьи.** В q2 (baseline) судья поставил «неверно» с комментарием «не предоставлен ответ», хотя ответ верный и подтверждён цитатой. С поправкой baseline даёт 5 верных ответов.
- **Цена правила «нет цитаты — нет ответа».** Пока разбор цитат ошибался, правило отклоняло и верные ответы. Это вскрыли первые прогоны, и разбор исправлен: две цитаты после одного [n], склейка через «[…]», вложенные кавычки («…по кличке «Сектоид».»). Теперь ни один верный ответ не отклоняется из-за цитат. Одиночное слово цитатой не считается.
